**MoviePilot**（[jxxghp/MoviePilot](https://github.com/jxxghp/MoviePilot) 核心引擎）的 fnOS Native 原生封装：以原生进程方式运行在飞牛 OS 上，从 fnOS 桌面点图标即用，无需 Docker。

<!-- 附件：界面演示截图 -->

## 它能做什么

- **资源搜索与订阅**：聚合站点搜索，想看的片子一键订阅，出资源自动下载、自动整理入库
- **整理与刮削**：下载完成后自动识别、重命名、刮削海报剧照，按媒体库结构归档
- **转移与硬链接**：支持复制 / 移动 / 硬链接等整理方式，配合媒体服务器秒速入库
- **媒体服务器对接**：内置飞牛影视（trimemedia）对接，入库即可看
- **通知**：企业微信 / Telegram / Bark 等渠道推送订阅、整理结果
- **更多能力**：站点数据、文件管理、插件市场等，详见 MoviePilot 官方文档

## 封装特性（fnOS 原生体验）

- **统一网关访问**：fnOS 桌面点击图标直接打开（`/app/moviepilot`），自动免登录
- **离线安装**：全部依赖内置在 fpk 中（约 424MB），安装无需外网、无需 SSH，1~5 分钟完成
- **以专用用户运行**：应用以独立系统用户（moviepilot）非特权运行，权限收口
- **目录授权走原生入口**：媒体库、下载目录等用户目录，直接用 fnOS 应用设置里的「配置访问权限」授权，授权即在 MoviePilot 目录浏览器中可见可用
- **端口可绑定**：前端（默认 3000）/ 后端（默认 3001）端口如与其他应用冲突，安装向导或配置向导中可直接修改

## 安装

1. 下载 fpk 安装包（见本帖附件，按设备架构选择 x86 / arm 版本）
2. fnOS **应用中心 → 手动安装**，选择 fpk 文件上传
3. 按安装向导设置管理员账号（及端口，保持默认可直接下一步）
4. 桌面出现 MoviePilot 图标，点开即用

> 更新方式：下载新版 fpk 覆盖安装即可，配置和数据都在共享区，不会丢失。

## 首次配置建议

1. **授权目录**：fnOS 应用设置 → MoviePilot →「配置访问权限」，把媒体库、下载目录选进去。授权后 MoviePilot 的目录选择器里就能逐级点到这些目录（未授权的目录不可见）
2. **账号**：安装向导设置的管理员账号同时用于桌面图标免登录；若之后在 MoviePilot 网页里改了密码，记得在 fnOS 应用设置的配置向导里同步更新免登录密码
3. **端口**：默认 3000/3001，冲突时在向导中改

## 常见问题

**Q：目录选择器里看不到我的媒体库目录？**
先用 fnOS 应用设置的「配置访问权限」把目录授权给应用。授权后即时生效，无需重启；目录浏览器中只展示已授权的路径。

**Q：3000 端口被占了？**
安装向导的「端口设置」步骤，或之后在配置向导里修改前端/后端端口，应用会自动重启生效。

**Q：怎么更新版本？**
下载新版 fpk，应用中心手动安装覆盖。MoviePilot 网页内的在线更新入口已停用（会破坏封装的离线依赖结构）。

**Q：数据存在哪里？**
配置和数据都在 fnOS 共享区（文件管理器可见），卸载应用不会删除用户数据。
